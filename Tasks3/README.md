# Project Overview

This project demonstrates SQL-based data analysis using a MySQL sample database.
It includes data retrieval, filtering, sorting, aggregations, joins, subqueries, views, and query optimization techniques.

---

# Database Used

**mysqlsampledatabase.zip**
Contains the MySQL sample database schema and data used for analysis.

---

# SQL Queries

**SQL_Queries.sql**

Includes SQL queries written for:

* SELECT statements
* WHERE filtering
* ORDER BY sorting
* GROUP BY aggregations
* SUM, AVG, COUNT functions
* INNER, LEFT, RIGHT JOINs
* Subqueries and correlated subqueries
* Views creation
* Index optimization
